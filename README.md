# Abschlussprojekt_AnalyseAktienmaerkte

## Teilprojekt 1: Automatisierte Morgenroutine für den Börsenhandel 

### Projektziel: 
Diese Routine soll in Anlehnung zu einem Gesundheitscheck aufgebaut werden.
Wir möchten im Ergebnis ausdrücken, ob sich auswählte Märkte tendenziell in einem ruhigen Fahrwasser, in einer angespannten Umgebung oder einem absoluten Ausnahmezustand befinden. Das Ergebnis unserer Analyse soll jeweils in einem Ampel-System ausgedrückt werden.

### Forschungsfrage: 
Unterscheiden sich die zukünftigen 1-, 5- und 20-Handelstage-Renditen zwischen einem positiven und einem negativen SMA-20/50-Regime?
